# SQLite для локальных тестов и PostgreSQL для рабочего запуска

PostgreSQL — рабочая СУБД CRM. Схему определяют SQL-миграции в
`backend/migrations/`; `backend/scripts/migrate.py` отказывается выполнять их
на SQLite.

В `backend/app/config.py` адрес `sqlite:///./dev.db` служит значением по
умолчанию для локальных unit-тестов и скриптов, которым не нужна рабочая схема.
Контейнер backend требует `DATABASE_URL` и без него не запускается.

Для интеграционных тестов используйте отдельную базу PostgreSQL через
`TEST_DATABASE_URL`. Текущий `GET /ready` сообщает о готовности процесса и
сам по себе не проверяет соответствие схемы PostgreSQL. Поэтому запуск
`uvicorn` с SQLite допустим только для локальной отладки без рабочих данных.
