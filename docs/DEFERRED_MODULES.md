# Изолированные модули backend

В `backend/app/modules/` остаются устаревшие заготовки `documents`, `identity`,
`programs`, `reporting` и `workflow`. Их routers не подключены к
`app/api/router.py`; отдельные модели используют `DeferredBase` и не входят
в рабочую схему PostgreSQL. Рабочие API этих областей реализованы в
канонических модулях приложения.

Перед подключением любого изолированного модуля необходимо привести его
идентификаторы к UUID, добавить SQL-миграцию, сервисный слой, проверку прав и
области доступа, пагинацию и аудит. После этого нужно проверить маршруты и
схему на PostgreSQL. Тест `backend/tests/test_p0_deferred_registry.py`
контролирует изоляцию текущих заготовок.
