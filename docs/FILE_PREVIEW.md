# Предпросмотр прикреплённых файлов

Реализация подключена к AttachmentRow (вложения workflow, комментарии и история вуза), файлам договоров и документам паспорта вуза, включая мобильное представление таблиц.

Шторка открывается спустя 180 мс наведения или фокуса. На устройствах без hover первое нажатие открывает предпросмотр, следующее сохраняет действие файла. Есть кнопка закрытия, Escape и закрытие по нажатию снаружи. Задержка ухода — 300 мс, анимация — 160 мс, учитывается reduced motion. При переходе на другую шторку запрос предыдущей отменяется. Скелетон зависит от предполагаемого типа; изображение заменяет его только после загрузки браузером.

## Форматы и ограничения

- PNG/JPEG: реальные байты, определение по сигнатуре; до 8 МиБ и 25 миллионов пикселей, сохранение пропорций, масштабирование колесом мыши (100–500%) и перетаскивание увеличенного изображения. Повреждённые изображения дают сообщение об ошибке.
- PDF: первая страница рендерится в PNG через pypdfium2/PDFium в изолированном процессе. Максимальный растр — 1200 × 1600 пикселей, с сохранением пропорций. JavaScript и активное содержимое не передаются браузеру. Показаны номер страницы и общее число страниц; есть приближение колесом мыши. Файлы с паролем, повреждённые и слишком сложные PDF дают контролируемую ошибку.
- DOCX: первые 60 абзацев, заголовки и маркеры списков; таблицы, изображения и сложное форматирование опущены. XML до 2 МиБ; DTD и объявления сущностей отклоняются. HTML не генерируется.
- DOC: сообщение о недоступности предпросмотра и сохранение скачивания.
- XLS/XLSX: первый лист, до 20 строк × 10 столбцов, ячейки до 500 символов; прокрутка, координаты. Формулы не вычисляются; XLSX использует сохранённые значения. Внешние связи не загружаются.
- ZIP/RAR: имена с полным относительным путём, расширения, каталоги и размеры; страницы по 100 записей, максимум 10 000 записей. Файлы не извлекаются. Вложенные пути отображаются текстом, без раскрывающегося дерева. Зашифрованные заголовки и повреждённые архивы дают сообщение об ошибке.
- GZIP: имя одного потока из заголовка либо имени файла. Размер распакованного потока не заявляется: ISIZE ненадёжен для больших и составных потоков. Вложенный TAR не распаковывается.

## API и безопасность

Добавлены GET-маршруты с `offset` (0–9900):

- `/api/v1/workflow/instances/{instance_id}/attachments/{attachment_id}/preview`
- `/api/v1/contracts/{contract_id}/file/preview`
- `/api/v1/universities/{university_id}/passport/documents/{document_id}/preview`

Каждый маршрут повторяет существующую цепочку проверки права чтения, доступа к вузу и принадлежности файла сущности. Запросы используют существующий apiFetch с Keycloak и обновлением токена. Данные не отправляются сторонним сервисам, не записываются в browser storage и выдаются с Cache-Control: no-store.

Извлечение выполняется отдельным Python-процессом из синхронного маршрута FastAPI (пул потоков): 4 секунды CPU, 6 секунд ожидания процесса, 384 МиБ адресного пространства на Linux, максимум два параллельных извлечения на процесс сервера. Копирование из хранилища потоковое во временный каталог, максимум 50 МиБ; каталог удаляется при выходе. Между чтениями проверяется бюджет копирования 8 секунд; сетевой timeout самого чтения задаётся транспортом хранилища. Ограничение памяти через RLIMIT_AS на macOS не применяется. Архивы не распаковываются на диск; абсолютные пути и traversal отклоняются в выдаваемых записях.

Результаты успешного извлечения кэшируются на сервере до 60 секунд, максимум 24 результата и 24 МиБ JSON. Кэш привязан к экземпляру хранилища, неизменяемому случайному ключу объекта, имени и смещению. Проверки прав и метаданных выполняются перед каждым обращением к кэшу, в том числе при повторном наведении. Замена файла создаёт новый ключ; удалённое вложение больше не проходит поиск метаданных. Ошибки не кэшируются. Клиент отменяет устаревшие запросы; уже начавшийся серверный процесс ограничен своим timeout.

## Библиотеки

Существующие React, React DOM portal, Next Image, apiFetch/Keycloak, openpyxl и xlrd. Добавлены серверные зависимости `pypdfium2==5.14.0` (первая страница PDF) и `rarfile==4.2`: для чтения списка RAR внешний unrar не нужен. ZIP, GZIP-заголовки и DOCX используют стандартную библиотеку Python. Зависимости указаны в pyproject.toml и устанавливаются при сборке Docker.

## Обновление анимации и PDF

Открытие/закрытие использует короткий fade через opacity (160 мс). Масштабирование, смещение и анимация координат отключены: шторка сразу позиционируется рядом с файлом, без вылета из начальной точки viewport. Таймеры открытия, задержки ухода и размонтирования раздельные. Активная шторка не вызывает собственное закрытие при повторном наведении. Возврат во время закрытия отменяет размонтирование и разворачивает текущую анимацию, сохраняя содержимое и запрос. Позиция выбирается сначала справа/слева (удобный переход через промежуток 10 px), затем снизу/сверху; размеры учитывают пропорции изображения и viewport. Скелетон остаётся смонтированным и затухает одновременно с появлением результата. Уменьшенное движение использует fade 30 мс без масштабирования.

Регрессии PDF: backend/tests/test_file_preview_render.py (реальный отдельный процесс, первая из двух страниц, повреждённый и зашифрованный документ, большая страница).
