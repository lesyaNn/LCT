## Запуск

При работающем Docker Compose из корня проекта:

```bash
python backend/scripts/start_assistant.py
```

Существующий стенд с `ASSISTANT_MODEL=qwen3:4b` в локальном `.env` сохранит свой выбор. Для проверенного CPU-профиля укажите `ASSISTANT_MODEL=qwen3:1.7b` либо передайте `--model qwen3:1.7b`. Скрипт нужно повторно запустить после обновления кода: сам push не разворачивает модель на стенде. [Параметры и API](ASSISTANT.md).

## Локальный бэкап

В рабочем клоне настроен `pre-push` hook. Перед каждой отправкой он сохраняет и проверяет Git bundle со всей историей и ветками, ZIP текущего коммита, патчи незакоммиченных изменений и неигнорируемые новые файлы. Если бэкап не удался, push останавливается.

Бэкапы находятся в `C:\Users\Raisw\LCT-backups`. Локальные базы, секреты, веса моделей и другие игнорируемые runtime-файлы туда не входят. Hook локальный, в другие клоны автоматически не переносится.
