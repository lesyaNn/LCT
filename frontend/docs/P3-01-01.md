# P3-01-01 — Основной App Shell CRM

## Техническая реализация

- Next.js App Router для маршрутизации.
- Общая оболочка реализована через `app/(crm)/layout.tsx` и переиспользуемые widgets.
- Для интерактивных частей используются точечные Client Components (`usePathname`, состояние drawer/dropdown/collapse).
- Стилизация — CSS Modules и локальные semantic aliases токенов Rostelecom Design System 2.0.

## Функциональные требования

App Shell содержит Sidebar, Topbar, автоматические Breadcrumbs, User Menu и адаптивную content area. Навигация использует единый typed config, а видимость пункта администрирования — frontend mock role `admin`.

## Auth boundary

Ветка сохраняет совместимость с существующим realm `rtk` и клиентом `rtk-frontend`:
`shared/lib/keycloak-adapter.ts` содержит безопасный browser-only singleton, PKCE S256,
refresh по истечению токена и logout. Для P3-01-01 адаптер намеренно не вызывается —
App Shell работает с mock-пользователем, как требует текущий этап. Подключение выполняется
отдельной auth-задачей через `NEXT_PUBLIC_AUTH_MODE=keycloak`; токены не записываются в
`localStorage`.

Для локального P3 запуска достаточно оставить переменную unset (режим `mock`). При отдельном
подключении auth перед сборкой задаются `NEXT_PUBLIC_AUTH_MODE=keycloak`,
`NEXT_PUBLIC_KEYCLOAK_URL`, `NEXT_PUBLIC_KEYCLOAK_REALM` и `NEXT_PUBLIC_KEYCLOAK_CLIENT_ID`.

Связь с существующим FastAPI сохранена в `shared/lib/api-client.ts`: он поддерживает Bearer,
refresh, 401/204 и JSON guards, но пока не вызывается страницами App Shell.
