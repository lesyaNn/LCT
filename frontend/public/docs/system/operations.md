Техническое обслуживание стенда выполняет системный администратор. Эта статья описывает действующий порядок на уровне системы, без внутренних путей проекта.

## Запуск и проверка

Перед запуском задайте безопасные пароли и адреса сервисов в настройках окружения. Поднимите сервисы CRM, затем убедитесь, что база данных, служба авторизации, API и веб-приложение здоровы. Миграции выполняются при старте API.

## Демонстрационный стенд

Режим демонстрации включается серверной настройкой `DEMO_MODE=true`. Он показывает выбор трёх существующих ролей на странице входа; сама авторизация по-прежнему проходит через Keycloak. В обычной конфигурации режим выключен.

## Резервное копирование и ошибки

Сохраняйте базу данных и постоянные хранилища файлов и отчётов. При ошибке проверьте состояние нужного сервиса и его журнал, затем состояние службы авторизации и миграций. Доступ к технической документации API открывается на сервере API. Секреты, токены и резервные копии нельзя публиковать в CRM.
