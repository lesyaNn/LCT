Администратор открывает **Администрирование → Шаблоны Workflow**. Шаблон задаёт маршрут для **новых** процессов: названия и порядок этапов, активность, обязательность, оценку срока и задачи по умолчанию. В списке можно создать шаблон, открыть существующий и показать отключённые.

![Список шаблонов Workflow](/docs/images/docs-workflow-templates-list.jpg)

## Редактировать этапы

Откройте шаблон. В редакторе у каждого этапа есть название, кнопка **Задачи этапа**, переключатели **Обязателен** и **Активен**, оценка дней и действия. Значок карандаша меняет название; стрелки или перетаскивание меняют порядок. **Добавить этап** создаёт новый пункт маршрута, корзина удаляет ненужный этап из проекта шаблона. Необязательный этап можно пропустить при разрешённом переходе, а отключённый не должен использоваться в новом маршруте. Проверьте порядок и сохраните изменения шаблона.

![Редактор этапов, сроки и переключатели](/docs/images/docs-workflow-template-editor.jpg)

## Задачи этапа по умолчанию

Нажмите **Задачи этапа** у нужной строки. В модальном окне **Задачи этапа по умолчанию** нажмите **Добавить задачу**, введите её название; существующую задачу можно изменить или удалить. Нажмите **Сохранить** в окне, затем сохраните редактор шаблона. При запуске нового Workflow эти задачи появятся в соответствующем этапе невыполненными. Пока обязательные задачи текущего этапа не закрыты, переход блокируется.

![Актуальное окно «Задачи этапа по умолчанию»](/docs/images/docs-workflow-default-tasks.jpg)

Изменения шаблона применяются к новым Workflow. Уже запущенные процессы сохраняют свою последовательность и созданные задачи. Отключённый шаблон нельзя выбрать при запуске нового процесса; существующие процессы при этом не исчезают. Для проверки правок запустите новый Workflow на тестовых данных.
