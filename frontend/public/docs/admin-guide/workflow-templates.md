Шаблон задаёт этапы для новых Workflow. Откройте **Администрирование → Шаблоны Workflow**. Здесь можно создать шаблон, открыть существующий и показать отключённые.

В редакторе задайте название и последовательность этапов. Для каждого этапа настройте название, активность, обязательность и плановый срок. Проверьте порядок перед сохранением: именно его увидит сотрудник в новом процессе. Необязательный этап можно пропустить при допустимом переходе.

![Редактор шаблона с последовательностью этапов](/docs/images/docs-workflow-template-editor.jpg)

Нажмите **Задачи этапа** у нужного этапа, чтобы добавить задачи по умолчанию. Укажите понятные названия и сохраните список. При запуске нового Workflow задачи активных этапов появятся невыполненными; пока задачи текущего этапа не выполнены, переход дальше блокируется.

![Настройка задач этапа по умолчанию](/docs/images/docs-workflow-default-tasks.jpg)

Изменение шаблона применяется к новым запускам. Уже созданный Workflow сохраняет свою последовательность и задачи, поэтому для проверки изменений создайте новый процесс на тестовых данных. Отключённый шаблон нельзя выбрать для нового Workflow.
