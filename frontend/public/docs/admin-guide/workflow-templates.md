> Для администратора.

Шаблон определяет состав и порядок этапов, по которым затем идёт работа с вузом. Откройте **Администрирование → Шаблоны Workflow**, чтобы посмотреть существующие шаблоны и перейти к редактору.

При изменении названий, порядка и настроек этапов проверяйте, как шаблон будет выглядеть в новом Workflow. Уже созданные процессы могут сохранять свою историю; не описывайте демонстрационный набор этапов как обязательный для всех шаблонов.
