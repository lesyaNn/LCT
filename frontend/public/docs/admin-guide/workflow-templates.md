> Для администратора.

Шаблон определяет состав и порядок этапов, по которым затем идёт работа с вузом. Откройте **Администрирование → Шаблоны Workflow**, чтобы посмотреть существующие шаблоны и перейти к редактору.

При изменении названий, порядка и настроек этапов проверяйте, как шаблон будет выглядеть в новом Workflow. Уже созданные процессы могут сохранять свою историю; не описывайте демонстрационный набор этапов как обязательный для всех шаблонов.

Чтобы настроить задачи по умолчанию, в редакторе нажмите **Задачи этапа** под названием нужного этапа. Добавьте задачи, укажите названия и нажмите **Сохранить**. В этом же окне можно переименовать или удалить задачи.

При запуске нового Workflow задачи всех активных этапов автоматически появятся в разделе **Задачи этапа** с отметкой «не выполнено». Изменение шаблона влияет только на новые запуски: задачи уже созданных процессов остаются прежними.
