**Для администратора.** В разделе **Администрирование → Пользователи и права** видны сотрудники, их роль, доступные вузы и состояние учётной записи.

Нажмите **Пригласить пользователя**, чтобы добавить сотрудника. В карточке пользователя можно настроить роль и список доступных вузов, заблокировать или разблокировать учётную запись и отправить письмо для смены пароля, если эти действия доступны.

![Форма настройки пользователя и области доступа](/docs/images/users-rights.png)

Администратор видит все вузы. Руководителю и пользователю назначаются конкретные вузы; без назначения список данных может быть пустым.
