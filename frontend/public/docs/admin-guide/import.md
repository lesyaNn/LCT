Импорт доступен администратору в разделе **Администрирование → Импорт каталогов**. Он загружает данные из Excel в справочники CRM. Проверьте файл и результат пробного запуска до записи.

1. Скачайте **тестовый файл**, если нужен пример структуры. Подготовьте XLSX или XLS с названиями листов и колонок по образцу.
2. Загрузите файл. Система покажет найденные листы и количество строк.
3. Выберите один лист или **Все листы файла**. Для одного листа проверьте предпросмотр строк. При импорте всех листов порядок обработки учитывает зависимости между справочниками.
4. При необходимости включите **Обновлять существующие записи**. Это меняет найденные записи, поэтому проверьте настройку перед пробным запуском.
5. Нажмите **Запустить dry-run** для одного листа или **Проверить всё** для всех. Пробный запуск показывает ошибки по строкам и не записывает данные.
6. Исправьте ошибки в файле и повторите проверку. После успешной проверки нажмите **Импортировать** или **Импортировать всё**.
7. Проверьте итог и **Журнал импортов**. Если параметры были изменены после проверки, проведите новый dry-run.

![Загрузка файла в разделе «Импорт каталогов»](/docs/images/docs-import.jpg)

Если часть строк содержит ошибки, интерфейс может предложить пропустить их при итоговом импорте. Используйте этот вариант только после просмотра отчёта об ошибках: пропущенные строки не появятся в справочнике.
