**Для администратора и сотрудников с правом импорта.** Импорт расположен в **Администрирование → Импорт каталогов**.

1. Нажмите **Скачать тестовый файл**, если нужен пример заполнения.
2. Загрузите Excel-файл. Система покажет доступные листы.
3. Выберите один лист или **Все листы файла**. Сопоставление колонок выполняется сервером.
4. Проверьте предпросмотр строк и параметры обновления существующих записей.
5. Нажмите **Запустить dry-run** (для всех листов — **Проверить всё**). Проверка не записывает данные.
6. Исправьте ошибки по строкам и повторите проверку. После успешной проверки нажмите **Импортировать**.
7. Откройте журнал импортов, чтобы увидеть итог и ошибки.

![Загрузка Excel и ссылка на тестовый файл](/docs/images/import.png)

> **Важно.** Параметры, изменённые после проверочного запуска, требуют новой проверки перед импортом.
