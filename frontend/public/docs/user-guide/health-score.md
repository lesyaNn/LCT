**Health Score** показывает текущее состояние взаимодействия с вузом по данным CRM. Это не академический рейтинг. Откройте паспорт и вкладку **Health Score**.

Вверху находятся оценка, число активных Workflow, количество процессов, требующих внимания, и охват ИТ-программ. Ниже раскрыты факторы: просроченные текущие этапы и задачи, отсутствие ответственного, сроки связанных лицензий. Нажмите на связанную запись, чтобы перейти к её Workflow.

![Текущая оценка Health Score и факторы внимания](/docs/images/docs-health-score.jpg)

## Как читать оценку

- **Стабильно** — по доступным данным нет существенных проблем.
- **Требует внимания** — есть факторы, которые стоит проверить.
- **Критично** — обнаружены серьёзные проблемы взаимодействия.
- **Недостаточно данных** — считать оценку пока не из чего.

Программы без запущенного Workflow отмечаются отдельно и не заменяются придуманной оценкой. График динамики показывает только реально сохранённые наблюдения; одна точка означает, что сравнивать пока не с чем. Ниже можно посмотреть оценку по ИТ-программам и блок **Требует внимания**.

На [Обзоре](/docs?article=user-guide%2Foverview) матрица **ВУЗы × программы** позволяет сравнить состояния связей. В ней есть отдельные состояния **Не запущено**, **Завершён** и отсутствие связи.
