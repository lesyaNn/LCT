В верхней панели CRM поле **Поиск по системе** ищет доступные вам вузы, Workflow, документы, договоры, продукты, ответственных, личные заметки и разделы. Начните вводить название и выберите результат из сгруппированного списка. Состав результатов зависит от роли и назначенных вузов; чужие личные заметки не показываются.

![Глобальный поиск с результатами по вузам, Workflow и документам](/docs/images/docs-system-search-20261020.jpg)

В разделе **Документация** есть отдельный **Поиск по документации**. Он ищет по названиям статей, заголовкам и тексту инструкций. Результат открывает статью внутри справочного центра, а не объект CRM. На телефоне меню статей раскрывается кнопкой **Навигация по документации**.

Если результат не появился, проверьте написание и область доступа. Для поиска вузов в конкретном списке также сбросьте его фильтры. Начальный маршрут описан в [Начале работы](/docs?article=user-guide%2Fgetting-started).
