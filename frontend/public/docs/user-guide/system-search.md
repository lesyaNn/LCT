**Поиск по системе** находится в верхней панели CRM. Начните вводить название вуза, Workflow, документа, договора, продукта, ответственного, [личной заметки](/docs?article=user-guide%2Fnotes) или раздела. Выберите результат, чтобы открыть доступный объект. Состав результатов зависит от вашей роли и назначенных вузов; чужие заметки в поиске не появляются.

В разделе **Документация** есть своё поле **Поиск по документации**. Оно ищет по названиям статей, заголовкам и тексту инструкций. Нажмите результат, чтобы открыть статью. На телефоне сначала откройте меню **Навигация по документации**.

Если нужного результата нет, проверьте написание, фильтры на странице и область доступа. [Начало работы](/docs?article=user-guide%2Fgetting-started) поможет найти нужный раздел.
