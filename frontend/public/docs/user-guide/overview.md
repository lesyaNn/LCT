**Обзор** — рабочая панель по доступным вам вузам. Показатели отражают записи CRM и выбранные фильтры, а не всю сеть, если доступ ограничен.

## Общие фильтры и показатели

Вверху выберите **ВУЗ**, **ИТ-направление**, **ИТ-продукт**, **Ответственного** и **Период**. Для периода есть готовые интервалы и даты **От / До**. **Сбросить** возвращает исходную выборку. Перед сравнением двух показателей проверьте период и активные фильтры.

![Обзор: фильтры и ключевые показатели](/docs/images/docs-dashboard-20261020.jpg)

| Карточка | Что означает и куда ведёт |
|---|---|
| **ВУЗы** | Число вузов в доступной выборке; переход в список вузов. |
| **Просроченные этапы** | Текущие этапы Workflow с прошедшим сроком; переход к отфильтрованным Workflow. |
| **Истекающие лицензии** | Лицензии со сроком окончания в ближайшие 30 дней; проверьте их в паспортах вузов. |
| **Активные программы** | Программы с текущим активным статусом в доступной выборке. |
| **Заявки с сайта за 7 дней** | Счётчик загруженных заявок, если интеграция поставляет данные; карточка ведёт к связанным вузам. |
| **Обучающиеся LMS** | Агрегированное число учащихся из LMS, когда интеграция и данные доступны. |

Пустой счётчик не доказывает, что событий во внешней системе нет: данные могли ещё не поступить в CRM.

## Графики и рабочие сигналы

- **Воронка этапов** показывает, сколько взаимодействий дошло до каждого этапа или дальше. Столбцы уменьшаются по мере прохождения маршрута; резкое падение помогает найти участок, на котором процессы задерживаются. Это накопленная картина за всё время.
- **Приоритетные задачи** перечисляют ситуации, требующие внимания, например просроченные этапы. В строке видны приоритет, вуз, причина и длительность просрочки. Нажатие открывает паспорт соответствующего вуза, откуда можно перейти к Workflow.
- **Динамика запусков** сравнивает фактические и планируемые запуски программ за последние 12 месяцев. Смотрите не только на общий рост, но и на расхождение линий.
- **Динамика по месяцам** показывает события, смены статусов и завершённые Workflow по месяцам. График помогает увидеть периоды всплеска активности; он строится по сохранённым событиям CRM за всё время.
- **Топ-10 ВУЗов по числу взаимодействий** считает сохранённые встречи и заметки. Высокий столбец означает больше зафиксированных контактов, а не качество отношений.
- **Нагрузка по ответственным** сравнивает назначенные сотрудникам Workflow в работе и завершённые. Строка **Без ответственного** подсказывает, где требуется назначение.
- **Программы по статусам** показывает текущее распределение программ реестра: запланированные, активные и запущенные. Сектор и подпись дают количество и долю.

Наведение на точку, сектор или столбец раскрывает число. В карточке с данными меню **Скачать** сохраняет график как **PNG** или **PDF**; это изображение графика, не выгрузка исходных строк. Если данных для карточки нет, скачивание может быть недоступно. Для табличной выгрузки используйте [Отчёты](/docs?article=user-guide%2Freports).

## Матрица «ВУЗы × программы»

Строки — вузы, столбцы — ИТ-программы. В каждой ячейке показано состояние **конкретной связи** вуза с программой:

| Состояние | Значение |
|---|---|
| **Стабильно** (зелёный) | Запущенный или завершённый процесс без факторов внимания на текущих данных. |
| **Требует внимания** (оранжевый) | Есть факторы, которые нужно проверить в Workflow и Health Score. |
| **Критично** (красный) | Есть серьёзный фактор риска. |
| **Не запущено** (серый) | Программа связана с вузом, но Workflow ещё не создан. |
| **Завершён** | Workflow завершён; это отдельное состояние процесса. |
| **Прочерк** | У вуза нет связи с этой программой. |

![Матрица «ВУЗы × программы» в текущем Обзоре](/docs/images/docs-dashboard-matrix-20261020.png)

Нажмите название вуза для паспорта. Ячейка с запущенным процессом ведёт к его Workflow; для ещё не запущенного процесса откроется паспорт, где его можно создать при наличии права. На узком экране прокрутите матрицу горизонтально. Итоговая оценка в строке вуза объясняется в отдельной статье [Health Score](/docs?article=user-guide%2Fhealth-score).
