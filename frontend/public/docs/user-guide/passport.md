Паспорт объединяет данные конкретного вуза. Откройте **ВУЗы** и выберите организацию. В шапке показаны название, город и местное время — оно помогает выбрать время для звонка, но не заменяет фактический график вуза.

![Паспорт вуза с девятью вкладками и карточками Workflow](/docs/images/docs-passport-overview.jpg)

## Что находится во вкладках

| Вкладка | Что видно и что можно сделать |
| --- | --- |
| **Обзор** | Ключевые показатели, Workflow по ИТ-программам и последние взаимодействия. При наличии права можно запустить процесс для программы без Workflow. |
| **Health Score** | Текущая оценка взаимодействия, причины снижения, охват программ и динамика сохранённых оценок. Перейти к проблемному Workflow можно из блока внимания. |
| **ИТ-продукты** | Подключённые продукты, поставщики, статусы и лицензии. Руководитель и администратор могут добавить связь с продуктом, если действие доступно. |
| **Лицензии** | Номера, сроки, статусы, передача и договоры. Есть фильтр по статусу и действие **Паспорт лицензии** с открытием или скачиванием PDF. |
| **Документы** | Переключатель **Договоры / Прочие документы**, файлы и сведения о записях. При наличии права можно прикрепить файл договора или добавить документ. |
| **Встречи** | Хронология встреч, участники, итоги и следующее действие. Руководитель и администратор могут добавить встречу. |
| **Ответственные** | Назначенные сотрудники и контакты вуза. При наличии права можно назначить или снять ответственного, скопировать контакт. |
| **Workflow** | Все процессы вуза, их ИТ-программы, статусы и прогресс. При наличии права можно создать новый процесс. |
| **История** | События этого вуза с датами и типами изменений. |

Права на просмотр паспорта и изменение данных различаются. [Пользователь](/docs?article=roles%2Fuser) работает с доступными ему вузами; редактирование данных в паспорте доступно [руководителю](/docs?article=roles%2Fmanager) и [администратору](/docs?article=roles%2Fadmin) в их области доступа.
