Раздел **API** нужен сотрудникам, которые настраивают интеграции с CRM. Он показывает контракт запущенного сервера: доступные методы, параметры запросов, ответы и требуемые права. Сам по себе просмотр страницы не выдаёт дополнительных прав.

1. Откройте **API** в левом меню. Найдите нужную операцию поиском или фильтром по HTTP-методу.
2. Откройте карточку метода и проверьте путь, обязательные параметры, пример ответа и разрешённые роли.
3. Нажмите **Скачать OpenAPI**, если нужен машиночитаемый JSON для клиента или инструмента тестирования.

Базовый путь методов — `/api/v1`. Для защищённых запросов используется токен пользователя; сервер проверяет его права и доступ к вузам так же, как при работе через интерфейс. Нельзя считать, что у каждой сущности есть полный набор создания, изменения и удаления: сверяйтесь с контрактом конкретного метода.

Не помещайте токены, пароли и секреты в комментарии CRM или публичные примеры. Для подключения внешней системы согласуйте техническую учётную запись и доступ с администратором. Обычные действия с вузами, Workflow и отчётами описаны в [руководстве пользователя](/docs?article=user-guide%2Fgetting-started).
