Роль **Пользователь** работает с назначенными вузами и доступными разделами CRM. Можно читать данные, вести разрешённые действия Workflow, оставлять комментарии и формировать отчёты. Раздел управления пользователями недоступен.

Если нужного вуза нет в списке, сначала сбросьте фильтры, затем попросите администратора проверить назначенную область доступа.
